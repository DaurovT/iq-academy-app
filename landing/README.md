# PharmIQ Academy — новый сайт

Статичный сайт (HTML/CSS/JS, без сборки). Весь контент перенесён с pharmiq.uz (RU + UZ).

## Дизайн
Редизайн 1.2 — по артбордам дизайн-канваса `Landing.dc.html` / `LandingLight.dc.html` (десктоп 1440)
и `LandingMobile.dc.html` / `LandingMobileLight.dc.html` (мобильный 390). Одна адаптивная страница:
десктоп-раскладка по умолчанию, планшет ≤1180px (бургер-меню, стопки), мобильная раскладка ≤760px.
Темы: тёмная по умолчанию, светлая — по `prefers-color-scheme` (переключателя в макете нет). Все токены — в `:root`
в `assets/css/style.css`; полоса «Платформа» тёмная в обеих темах (`--deep-*`).
Шрифты: Onest (заголовки) + Inter (текст), Google Fonts.
Анимации из макета: `lpUp`, `lpFloat`, `lpDrift`, `lpMarquee`, `lpPulse`, `lpMenu`; появление блоков при прокрутке —
IntersectionObserver (`.reveal`, задержка через `--d`). При `prefers-reduced-motion` анимации отключены.
Картинки макета: логотип-знак → `assets/img/mark.svg` (CSS-маска, цвет `--logo`), фото → `assets/img/hero.webp`.
В мобильной раскладке, как в макете, скрыты разделы «Платформа» и «Приложение» (класс `hide-m`),
«Партнёрам» — вкладками, «Преимущества» — каруселью.

## Структура
- `index.html` — лендинг: герой, О нас, Партнёрам, Платформа (видео + 6 шагов), Преимущества, приложение, заявка/контакты
- `user-agreement.html` — Пользовательское соглашение (только RU, как в оригинале)
- `privacy.html` — Программа лояльности (только RU, как в оригинале; на старом сайте эта страница висела под ссылкой «Конфиденциальность»)
- `assets/js/i18n.js` — все тексты RU/UZ, `assets/js/main.js` — логика
- `assets/img`, `assets/video` — ассеты со старого сайта

## Запуск локально
    python3 -m http.server 8080   # затем http://localhost:8080

Язык: переключатель RU/UZ, запоминается в браузере; можно открыть с `?lang=uz`.

## Заявка
Форма шлёт `POST https://api.pharmiq.uz/api/v1/web/form` (FormData: `pageID=main`, `contactNumber=998XXXXXXXXX`) — тот же API, что и на старом сайте.
Отправка в Telegram из браузера убрана: на старом сайте токен бота лежит в открытом JS. Если уведомления в Telegram нужны — отправляйте их с бэкенда.
