## Что вошло в релиз

Визуальный редизайн всего приложения: новый вид всех экранов, тёмная и светлая
темы по настройке системы, обучающий тур при первом входе. Функции, данные и
бизнес-модель не менялись — покупок в приложении по-прежнему нет.

## Сверка с макетами

Сравнены 203 пары «макет ↔ экран Flutter» (артборды канваса против снимков
визуальных тестов, одинаковые размеры). 152 из 197 сравнимых совпали с
расхождением меньше 5%.

Расхождения в верху списка оказались особенностями замера, а не ошибками:
- `Notif`, `Wallet`, `Upload` — макеты используют шаблоны канваса, которые
  локально не раскрываются;
- `SmsCode`, `LoginKeyboard` — в макете нарисована системная клавиатура,
  виджет-тесты её не рисуют;
- `PrivacyFull`, `Privacy` — в макете черновик текста, в приложении настоящий;
- `PhotoViewer` — в тесте нет фотографии-заглушки.

Настоящие находки, которые стоит доделать:
- `PullRefresh` / `PullRefreshLight` — визуальный тест снимает «Главную»,
  тогда как в макете «Мои чеки»: пары не соответствуют друг другу;
- нет снимков для `SapperGame`, `SapperGameLight`, `Toasts`, `ToastsLight`;
- в `PhotoViewer` у макета есть плашка масштаба «120%», в приложении её нет;
- 36 экранов обучающего тура сравнить нельзя: их макеты накладываются поверх
  других экранов.
