## Задача 1. Заявки по кодовому слову из приложения — видны в админке — готово

**Проблема.** Фармацевт, который ввёл кодовое слово медпреда в приложении (при регистрации или
из профиля — `POST /client/account/medrep-code`), попадает в «Ожидают подтверждения» у медпреда
(`GET /client/medrep/referrals/pending`, элементы с `kind: "app"`). В админке таких заявок не
видно нигде: `GET /admin/medreps/{mid}/pending` и `pendingCount` показывают только заявки из
бота (`pharm_ref_pending`). Поддержка не может проверить и принять заявку. Случай 19.11.2026:
медпред Мафтуна Бахрамова (medrep id 144, Bionorica SE, код BNO535) не видела двух фармацевтов;
их привязали вручную `POST /admin/users/{tid}/medreps`.

**Сделать:**

1. `GET /admin/medreps/{mid}/pending` — отдавать и заявки из приложения. У каждой записи:
   `id`, `kind: "app" | "bot"`, `source: "code" | "link"`, `name`, `phone`, `shop`, `city`,
   `requestedAt`. Для `kind: "app"` — ещё `accountId`.
2. `pendingCount` в `/admin/medreps`, `/admin/medreps/{mid}` и `pending` / `pendingMedreps` в
   `/admin/medreps-summary` — считать оба вида заявок.
3. Принять / отклонить заявку из приложения из админки. Либо расширить существующие
   `POST /admin/medreps/{mid}/pending/accept|reject` (параметр `kind`), либо отдельные
   эндпоинты. Логика — та же, что у `POST /client/medrep/team/pending/{id}/accept|reject`
   (фармацевт попадает в команду, уведомления те же).
4. В карточке пользователя-фармацевта (`GET /admin/users/{tid}` или карточке аккаунта
   приложения) — поле с ожидающей заявкой: к какому медпреду и с какого времени.
5. Если админка — отдельный фронтенд, показать заявки из приложения на экране медпреда
   («Ожидают подтверждения») с пометкой «из приложения».

**Проверка:** создать тестовую заявку из приложения (демо-фармацевт `+998 90 111 22 33`, код
00000, Профиль → «Кодовое слово медпреда»), убедиться, что она видна в
`/admin/medreps/{mid}/pending`, принимается из админки и после этого фармацевт есть в
`GET /client/medrep/team` медпреда.

## Задача 2. Бланки врачей в статистике медпреда — готово

**Проблема.** `GET /client/medrep/metrics` считает только чеки фармацевтов. У медпредов, в
команде которых врачи (Bionorica SE), все показатели — 0, хотя врачи отправляют сотни бланков.

**Сделать:** добавить в ответ `GET /client/medrep/metrics` (с теми же `from` / `to`) три поля:

```json
{
  "mode": "shared", "pharmCount": 17, "checksCount": 206, "approvedPacksSum": 266, "questsDone": 2,
  "recipesCount": 73,
  "approvedRecipes": 63,
  "recipePacksSum": 118
}
```

- `recipesCount` — бланки врачей команды медпреда за период, кроме отклонённых.
- `approvedRecipes` — из них одобренные.
- `recipePacksSum` — упаковки из одобренных бланков, только препараты компании медпреда.
- Врачи команды — те же, что в `doctors` из `GET /client/medrep/team`. Атрибуция (`mode`) — как
  у фармацевтов.
- `questsDone` — плюс закрытые рецептурные квесты врачей команды.
- Отдавать поля **всегда** (нули, если врачей нет): по наличию `recipesCount` приложение
  понимает, что сервер умеет считать бланки, и показывает плитку «Бланки».

## Задача 3. Рейтинг медпредов по бланкам и по врачам — готово

`GET /client/medrep/leaderboard?metric=...` сейчас знает `checks | pharm | quests`. Добавить:

- `metric=recipes` — одобренные бланки врачей команды;
- `metric=doctors` — сколько врачей в команде (аналог `pharm`).

Формат ответа прежний (`mode`, `metric` = запрошенное значение, `items[].rank/name/value/isMe`,
`myRank`, `company`). Сравниваются медпреды одной компании.

## Задача 4. Пересчёт показателей чаще раза в сутки — готово

Сейчас показатели медпредов (для `metrics`, `leaderboard`, `/admin/medreps`) пересчитываются раз
в сутки — `metricsAt` около 03:03 UTC (08:03 Ташкент). Днём рейтинг не меняется. Пересчитывать
хотя бы раз в 15–30 минут или считать на лету.

## Задача 5 (по желанию). Админка — готово

В `/admin/medreps` и `/admin/medreps/{mid}` — `doctorsCount`, `recipesCount`, `approvedRecipes`,
чтобы в админке была видна работа медпредов с врачами.

## Как проверить задачи 2–4

Под демо-медпредом (`+998 90 123 45 67`, код 00000) или медпредом Bionorica с врачами:

- `GET /client/medrep/metrics` и `?from=YYYY-MM-DD` — есть `recipesCount`, `approvedRecipes`,
  `recipePacksSum`; у медпреда без врачей — нули.
- `GET /client/medrep/leaderboard?metric=recipes` и `?metric=doctors` — `metric` в ответе
  совпадает с запрошенным, `items` отсортированы, `myRank` верный.
- Одобрить бланк врача команды в админке и через 15–30 минут (или сразу) увидеть изменение в
  `metrics` и `leaderboard`.
