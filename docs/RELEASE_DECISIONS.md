# Решения по релизу в App Store и Google Play

Зафиксировано 21.09.2026. Здесь — *что* решили и *почему*. Как собирать — в [BUILD.md](../BUILD.md),
как заполнять консоли — в [docs/store/console-guide.md](store/console-guide.md).

## Приложение и платформы
| Решение | Почему |
|---|---|
| Выпускаем **новым приложением**: iOS `uz.iqacademy.platformApp`, Android `uz.iqacademy.platform_app`, версия 1.0.0 | Не обновление старого PharmIQ (`com.spacelabs.pharmiq`) |
| **Только iPhone**, без iPad | Интерфейс сделан под телефон; не нужны скриншоты iPad |
| **Только вертикальная ориентация** (iOS и Android) | Экраны спроектированы под вертикаль |
| Скриншоты: 3 для App Store (1290×2796), 3 для Google Play (1080×1920), обложка 1024×500 | Цель — пройти модерацию, продвижение в сторах не планируется |

## Вход и аккаунт
| Решение | Почему |
|---|---|
| Вход: телефон + SMS, Telegram, **Google**, **Apple** | Apple требует «Войти через Apple», если есть другие внешние входы (4.8) |
| Google/Apple — «ключ» к аккаунту: при первом входе один раз подтверждается номер телефона | Аккаунт привязан к телефону, а через него — к баллам и ролям из ботов |
| Удаление аккаунта стирает персональные данные; записи о начислениях и ваучерах остаются без персональных данных | Требование Apple (5.1.1(v)) и Google; учёт начислений и розыгрышей не должен ломаться |
| Разрешение на уведомления спрашивается после входа | Рекомендация Apple |

## Тексты и механики
| Решение | Почему |
|---|---|
| Слово **«бланк»** вместо «рецепт» во всех текстах, на всех языках — навсегда | Решение продукта; дальнейшие изменения — только через обновления, проходящие проверку |
| Роль врача и отправка бланков **остаются** в релизе | Решение продукта |
| **«Супер Сапёр» остаётся** с механикой «клетка за баллы IQC → шанс на приз» | Решение продукта |
| У «Сапёра» есть официальные правила — в приложении (до участия) и на сайте | Apple 5.3: призовая акция допустима с опубликованными правилами |
| Призы размещаются **до запуска** розыгрыша и после старта **не меняются** (закрыто на сервере) | Это обещано в правилах; иначе итог мог бы зависеть от организатора |
| IQC: нельзя купить, передать или обменять на деньги; встроенных покупок нет | Так и описано в правилах и в заметках для проверки |
| **Korzinka остаётся** (экран ваучера и описания квестов) | Если стор спросит о правах на бренд — предоставим документы; лучше приложить их к App Review заранее (поле Attachment) |

## Данные и юридическое
| Решение | Почему |
|---|---|
| Оператор данных — ООО «PHARMIQ ACADEMY», контакт — support@pharmiq.uz | Реквизиты в политике: https://pharmview.uz/privacy |
| Фото чеков и бланков **удаляются автоматически через 4 месяца**; извлечённые из них данные (препараты, начисления, квесты) сохраняются | Минимизация персональных данных без потери истории квестов и участников |
| Обезличенные записи начислений хранятся 5 лет | Учёт; срок подтверждает юрист |
| В политике честно указано хранение данных на серверах в Литве | ⚠️ Вопрос юристу: закон РУз требует хранить данные граждан в Узбекистане |
| Данные пациентов на фото бланков — в политике есть оговорка | ⚠️ Вопрос юристу |

## Управление разделами
| Решение | Почему |
|---|---|
| В админке раздел «Приложение»: разделы можно **прятать и показывать** (для всех или по ролям) без новой сборки | Нужно для работы: сломанный раздел, сезонная игра, раздел не для всех ролей |
| Это только видимость — функции сервер не отключает | Данные и раздел можно вернуть в любой момент |
| **Не прятать функции на время проверки** в App Store / Google Play | Apple 2.3.1 — за это снимают приложение |

## Что остаётся сделать
1. Собрать релиз iOS (Mac) и Android — по [BUILD.md](../BUILD.md).
2. Заполнить App Store Connect и Play Console — по [console-guide.md](store/console-guide.md); приложить документы по Korzinka.
3. После первой загрузки в Google Play добавить SHA-1 ключа App Signing в Firebase.
