Всё, что нельзя исправить на сервере и что попадёт к людям только с новой сборкой в App Store и
Google Play. Последний релиз в сторах — **1.2.1 (сборка 4)**, отправлен 08.10.2026
(`docs/store/release-1.2.1-status.md`: «Команда» медпреда, кодовое слово, «Доп. проверка», правки
формулировок). Для нового релиза поднять версию в `pubspec.yaml` до **`1.2.2+5`**.

Когда пункт сделан в коде — перенести его в раздел «Готово в ветке». Перед сборкой этот раздел
становится списком изменений релиза.

## Готово в ветке `release/1.2-redesign` (после 1.2.1)

Сделано 26.10.2026, закоммичено 09.11.2026:

- **Вход через Telegram без регистрации.** Если этого Telegram нет в PharmIQ, приложение
  показывает «Этот Telegram ещё не зарегистрирован» и открывает регистрацию. Раньше — тост
  «Время входа истекло». Тексты на 5 языках (`tgNotRegistered`).
  Файлы: `social_login_buttons.dart`, `models/account.dart` (`TgPollExpired.reason`).
- **Пустой экран при переходе из уведомлений и пушей.** «Открыть чек», бланк, вкладки
  открываются через `openAppLink` (`lib/core/router/open_link.dart`): вкладка с нижним меню —
  через `go`, полноэкранный экран — через `push`. Раньше Flutter падал на
  `!keyReservation.contains(key)`. Проверено автотестом.
- **Пуш «Ваучер выдан»** открывает сам ваучер с QR (`/app/wallet/voucher/{id}`), а не кошелёк.

## Готово к 1.2.2 (09.11.2026)

Версия в `pubspec.yaml` — `1.2.2+5`. Источник жалоб — обход веб-версии 26.10.2026 и обращения
04–09.11.2026.

**Вход**
- **Больше не выкидывает на вход из-за связи.** Выход — только по ответу 401. При сетевой ошибке
  три попытки (через 2 и 5 с), потом — последний аккаунт из кэша (`TokenStore.readAccount`).
  Если нет и кэша, токен остаётся, и при следующем запуске сессия восстановится. Если
  `/auth/userCheck` отдаёт свежий `token`, приложение его сохраняет — так вход продлевается сам.
  Тест: `test/unit/auth_session_test.dart`.
- **Регистрация с уже существующим номером** (409) сразу ведёт на вход по этому номеру: номер
  подставлен, плашка «Этот номер уже зарегистрирован — войдите по коду из SMS» и кнопка
  «Ввести другой номер» (макет LoginRegistered).
- **Приветствие по имени, а не по фамилии** — на главных всех ролей, при выборе роли и после
  регистрации. ФИО читается как «Фамилия Имя Отчество»; если сервер пришлёт `firstName`,
  приложение возьмёт его.

**Отправка чеков и бланков**
- **Фото сжимаются** до 2000 px, качество 80 (~0,5 МБ вместо 5–25 МБ). Отдельный таймаут на
  загрузку: 5 мин на отправку, 2 мин на ответ.
- **Несколько чеков за раз:** до 10 фото, каждое — отдельный чек (макеты UploadPick, UploadPhotos,
  UploadDone). У бланка — до 5 фото из галереи.
- **Очередь не застревает.** Каждое фото чека — отдельный элемент. Отказ сервера по существу
  (4xx) помечает элемент «Не отправится», пропавшие файлы — «Фото не сохранилось», и очередь
  идёт дальше. Повтор — при появлении сети, возврате в приложение и каждые 2 минуты.
- **iPhone после обновления:** в очереди хранятся только имена файлов, путь собирается заново —
  чеки не теряются при смене папки приложения.
- **Android выгрузил приложение, пока была открыта камера**, — снимок подбирается при следующем
  запуске (`retrieveLostData`).
- **«Мои чеки» — блок «Ждут отправки»** (макет ChecksQueue): ждущие, «Не отправится», «Фото не
  сохранилось», кнопки «Удалить» и «Переснять».

**Чеки и бланки**
- «Нужно переснять» — только отклонённые за 30 дней и не с причиной «это не чек». Остальные
  отклонённые — в общей истории.
- Совет «Сделайте чёткое фото» не показывается, если причина «это не чек / не бланк».
- Полоска статусов отклонённого чека и бланка: «Отправлен → Отклонён».
- Одобренный бланк — «Засчитан в квест» вместо «Скоро начисление»: полоска «Отправлен →
  Проверка → Одобрен», все шаги заполнены (макеты RxApprovedNoQuest, RxList). Из шапки «Моих
  бланков» убраны IQC. Вариант с названием квеста ждёт сервер — `docs/server-todo.md`.

**Остальное**
- «Квесты» — в порядке из админки, без пересортировки и подписи «Сначала — ближе всего к награде».
- «Кошелёк» обновляется сам: при открытии, при возврате в приложение и при пуше о ваучере.
  В нижнем меню на «Кошельке» ничего не подсвечено (раньше — «Главная»).
- Медпред: кнопка «Копировать» в «Пригласить в команду» больше не обрезается.
- Медпред: карточка врача — из `GET /client/medrep/doctors/{accountId}` (макет MedDoctor):
  упаковки, квесты, дата в команде, последние 5 бланков. Врачи из бота — как раньше, из списка
  команды.
- Врач: блок «Ждут отправки» в «Моих бланках» (макет RxQueue). На каждый неотправленный бланк своя
  строка: миниатюра с «+N», если фото несколько; «Ждёт сети» / «Не отправится» / «Фото не
  сохранилось», у застрявших кнопки «Удалить» и «Переснять». Удаление — только через окно
  «Удалить бланк?» (RxQueueDelete): бланк есть только на телефоне.
- Медпред: карточка врача без бланков (MedDoctorEmpty): метка «Новый» вместо «Активный»,
  пустое состояние «Бланков пока нет».

## Сделано без релиза (для справки)

Эти правки уже работают у всех — на сервере, в админке и в данных. В релиз их включать не нужно.

- Ручной порядок квестов в приложении (Админка → Квесты → «Порядок в приложении»).
- Выдача ваучеров в приложение: канал «Только в приложение», запасной путь, если Telegram не
  доставил, поиск получателя по телефону и имени, пуш «Ваучер выдан».
- «Показать QR» из уведомления открывает экран ваучера (сервер отдаёт полноэкранную ссылку,
  работает и в 1.2.0).
- Вход через Telegram больше не создаёт аккаунт незнакомому человеку.
- Категории курсов: английская «General» заменена на категории из шаблонов.
- Видео урока «Тонзилгон Н» играет в приложении (настройки Vimeo).
- Исключения в таргетинге курсов и квестов: «кроме этих сетей / людей» (02.11.2026) — в
  приложении работает само (сервер не отдаёт исключённым курс или квест).
- **Вход в приложении — 180 дней** вместо 7, срок считается от выдачи токена — продлились и уже
  выданные (04.11.2026). Сменён секрет подписи токенов (был стандартный из примера) — все вошли
  заново один раз. Для релиза важно: токен по-прежнему не продлевается сам — см. пункт 0.
- Лимит загрузки на сервере 20 → 100 МБ на запрос (09.11.2026): несжатые фото чеков больше не
  получают 413. Сжатие в приложении всё равно нужно — пункт 0a.
- **Каждое фото из одной отправки — отдельный чек** (09.11.2026) — см. пункт 0b про тексты.
- Участник открывает свой завершённый (выключенный в админке) квест — раньше «Квест не найден» (09.11.2026).
- Сводка «Рецептов» в админке и весь API больше не тормозят из-за пересчёта подозрительных
  рецептов (09.11.2026) — на приложение влияло: в эти минуты могли подвисать запросы.

## Подготовка релиза — чек-лист

1. Сделать пункты из «Нужно сделать», прогнать `flutter analyze` и `flutter test`.
2. Версия в `pubspec.yaml` уже поднята до `1.2.2+5` (последняя в сторах — `1.2.1+4`).
3. После правок моделей — `dart run build_runner build --delete-conflicting-outputs`;
   после правок `.arb` — `flutter gen-l10n` (сгенерированные файлы форматировать `dart format lib/l10n/gen`).
4. Сборки: iOS — архив и загрузка в App Store Connect, Android — `flutter build appbundle`
   (подробности — `BUILD.md`, отчёт прошлого релиза — `docs/store/release-1.2.1-status.md`).
5. Тексты «Что нового» — по разделу «Готово в ветке» этого файла.
6. Веб-версию обновить на сервере: `./deploy_web.sh`.
